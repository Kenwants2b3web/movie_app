# Movie App

ITL313-18 SIA 2 Lab final term mini project.
A desktop app with a secure login system and a movie/TV search using the TMDB API.

## Features
- User registration and login (SQLite, salted and hashed passwords)
- Movie and TV show search (TMDB API) - in progress

## Setup
1. Clone the repo
2. Create a virtual environment: python -m venv venv
3. Activate it: venv\Scripts\activate
4. Install packages: pip install -r requirements.txt
5. Make a copy of .env.example, rename it to .env, and put your TMDB API key inside
6. Run the app: python main.py
